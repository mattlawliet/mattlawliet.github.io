## Projects

### Fabric Mods
| Mod | Description |
|-----|-------------|
| [Art Snap](https://modrinth.com/mod/art-snap) | Save, export, and import map art between worlds — full `.dat` cloning with name and enchantment preservation |
| [Matt's Mods](https://modrinth.com/mod/matt-mods) | Admin command utilities: changelog system and bed-triggered inventory backups |
| CAPSlock | Client-side sentence capitalizer for outgoing chat messages |
| Noted | In-game note-taking that persists across sessions |
| ptime | Client-side player time control without affecting server or other players |

### Paper Plugins
| Plugin | Description |
|--------|-------------|
| [Death On The Spot](https://modrinth.com/plugin/death-on-the-spot) | Full inventory saved to JSON on death with GUI-based chest retrieval |
| [Shopah](https://modrinth.com/plugin/shopah) | Sign-based item trading shops — no economy plugin required |
