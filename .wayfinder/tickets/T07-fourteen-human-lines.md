## Question

Every project gets a first line in the gallery-caption voice, sitting above the
existing precise one. Write all fourteen, with the user, in the user's voice.

The gap to close, using `ForkInteractions` as the example — currently:

> A thrown trident without Loyalty normally stays bound to whoever threw it.
> This releases that claim once it lands, which is what most people expect it
> to do.

Correct and unmemorable. The same person wrote "and- oh…" under a screenshot of
their own death.

This is a writing session, not a generation task: the agent proposes, the user
rewrites, nothing ships in a voice the user would not have used. Hardest cases
are the three with no media and no story yet — `Matt's Mods`,
`SuperUtilities`, `ForkInteractions` — and the two Python tools, which have to
be funny without the Minecraft frame.
